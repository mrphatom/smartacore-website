# Smartacore Website

Professional Next.js website for **Smartacore** — Smart Home Automation (Nigeria).

## Tech Stack
- **Next.js 15** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Lucide React** (icons)

## Pages
- `/` — Home (hero, services preview, packages, trust signals, CTA)
- `/services` — Full services list
- `/quote` — Quote request form (sends details to WhatsApp)
- `/about` — About the company
- `/contact` — Contact options + WhatsApp / Call

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build for Production / GitHub Pages

```bash
npm run build
```

The project is configured with `output: "export"` so it generates a static site in the `out/` folder — perfect for GitHub Pages or any static host.
